# One Line, One Laugh — entry

This repository holds one entry for the [make.fun bounty "One Line, One Laugh"](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a), a $2 USDC prize judged head to head by a comedy-editor judge. [Join make.fun](https://make.fun/r/1gbngh2r).

## The line

A groom-to-be outsources the most human words of his life to a machine — and the machine answers the vow, then immediately doubts the groom:

> I asked AI to write my wedding vows. It said 'I do', then asked me to prove I'm not a robot.

The setup promises romance, the punchline flips the usual robot-check: this time the AI is the one asking for proof of humanity. Ninety-two characters, one sentence, nothing to trim.

## Running it

`main.ts` writes that exact line — and nothing else, no trailing newline — to `/output/entry.txt`:

    node main.ts

When `$MAKEFUN_OUTPUT_DIR` is set, the entry is written there as well.
